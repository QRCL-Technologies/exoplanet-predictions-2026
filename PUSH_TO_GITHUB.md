## Troubleshooting

### Error: "git is not recognized"
**Solution:** Install Git from https://git-scm.com/download/win

### Error: "fatal: not a git repository"
**Solution:** Run `git init` first

### Error: "failed to push"
**Solution:** You may need to authenticate:
```powershell
git config --global user.email "pasinskis@gmail.com"
git config --global user.name "A9999998"
git push -u origin main
```

Then enter your GitHub username and **Personal Access Token** (not password) when prompted.
